Privacy Policy

Trivia Pipeline · Last updated: 10 October 2026

Trivia Pipeline ("the app") is a private tool used only by the owner of the Tricky Trivia and Tough Trivia YouTube channels to upload his own videos to his own channels. This policy explains what the app does with data.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses

  • The app requests one permission: youtube.upload, which lets it upload videos and set thumbnails on the signed-in user's channel.
  • It does not read, collect or store any other data from YouTube or Google: no viewer data, no comments, no analytics and no data about other users.

How data is stored

  • The OAuth access token is stored only on the channel owner's own computer, in a file readable only by that user. It is never sent anywhere except to Google's servers when uploading.
  • The videos, titles, descriptions and thumbnails are the channel owner's own content.

Sharing

No data is sold, shared with or disclosed to any third party.

Revoking access

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. Deleting the local token file also removes the app's access from the computer.

Data deletion

The app keeps no YouTube data. If access is revoked, or on request to the contact address below, the local token file is deleted immediately; nothing else needs deleting.
